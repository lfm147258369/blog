**作业1：多道程序运行时间计算（第1章）**

**题目描述**：设内存中有三道程序 A、B、C，它们按 A→B→C 的先后次序执行，它们进行"计算"和"I/O 操作"的时间如下表所示，假设三道程序使用相同的 I/O 设备。

| 程序 | 计算 | I/O 操作 | 计算 |
|------|------|----------|------|
| A | 20 | 20 | 10 |
| B | 30 | 40 | 20 |
| C | 10 | 20 | 10 |

试画出多道运行时三道程序的时间关系图，并计算完成三道程序要花多少时间。

**解析**

**时间线图**：

```mermaid
gantt
    title 多道程序运行时间线
    dateFormat  ss
    axisFormat %S

    section 程序A
    A计算1    : 0, 20ms
    A I/O     : 20, 20ms
    A计算2    : 40, 10ms

    section 程序B
    B计算1    : 20, 30ms
    B I/O     : 50, 40ms
    B计算2    : 90, 20ms

    section 程序C
    C计算1    : 50, 10ms
    C I/O     : 60, 20ms
    C计算2    : 80, 10ms

    section I/O设备
    I/O_A     : 20, 20ms
    I/O_B     : 50, 40ms
    I/O_C     : 80, 20ms
```

**关键分析**：
1. **0-20ms**：A 计算，B、C 等待
2. **20-40ms**：A I/O，B 计算（I/O 与计算并行）
3. **40-50ms**：A 计算完成，B 继续计算，C 等待
4. **50-60ms**：B I/O，C 开始计算
5. **60-80ms**：B I/O，C 等待 I/O 设备
6. **80-90ms**：B I/O，C 计算完成
7. **90-110ms**：B 计算完成

**总时间 = 110ms**

**作业2：进程同步（第3章）**

**题目描述**：进程之间的关系如下图所示，试用 P、V 操作描述它们之间的同步。

```mermaid
flowchart TD
    S1 --> S3
    S1 --> S4
    S1 --> S2
    S2 --> S5
    S4 --> S5
    S3 --> S6
    S5 --> S6
```

**进程依赖关系**：
- S3、S4、S2 都需要等待 S1 完成
- S5 需要等待 S2、S4 完成
- S6 需要等待 S3、S5 完成

**解析**

```c
// 定义信号量
semaphore s12 = 0, s13 = 0, s14 = 0;  // S1完成后通知S2,S3,S4
semaphore s25 = 0, s45 = 0;           // S2,S4完成后通知S5
semaphore s36 = 0, s56 = 0;          // S3,S5完成后通知S6

// 进程 S1
process S1() {
    // 执行 S1
    V(s12);  // 通知 S2
    V(s13);  // 通知 S3
    V(s14);  // 通知 S4
}

// 进程 S2
process S2() {
    P(s12);  // 等待 S1
    // 执行 S2
    V(s25);  // 通知 S5
}

// 进程 S3
process S3() {
    P(s13);  // 等待 S1
    // 执行 S3
    V(s36);  // 通知 S6
}

// 进程 S4
process S4() {
    P(s14);  // 等待 S1
    // 执行 S4
    V(s45);  // 通知 S5
}

// 进程 S5
process S5() {
    P(s25);  // 等待 S2
    P(s45);  // 等待 S4
    // 执行 S5
    V(s56);  // 通知 S6
}

// 进程 S6
process S6() {
    P(s36);  // 等待 S3
    P(s56);  // 等待 S5
    // 执行 S6
}
```

**作业4：分页存储管理地址计算（第5章）**

**题目描述**：在分页存储管理方式下，页面大小为 4KB，已装入内存。内存的作业的页表如下：

| 页号 | 块号 |
|------|------|
| 0 | 2 |
| 1 | 6 |
| 2 | 12 |
| 3 | 20 |
| 4 | 27 |

请计算下列逻辑地址所对应的物理地址：376, 2872, 18702, 4769, 20837。

**解析**

**地址转换流程**：

```mermaid
flowchart TD
    A[逻辑地址] --> B{计算页号}
    B --> C[页号 = 地址 / 4096]
    C --> D{查找页表}
    D --> E[获取块号]
    E --> F{页号有效?}
    F -->|是| G[物理地址 = 块号×4096 + 偏移]
    F -->|否| H[越界中断]
```

**页面大小 = 4KB = 4096 字节**

| 逻辑地址 | 页号 | 页内偏移 | 块号 | 物理地址 |
|----------|------|----------|------|----------|
| 376 | 0 | 376 | 2 | **8568** |
| 2872 | 0 | 2872 | 2 | **11064** |
| 18702 | 4 | 2318 | 27 | **113090** |
| 4769 | 1 | 673 | 6 | **25249** |
| 20837 | 5 | 525 | - | **越界** |
