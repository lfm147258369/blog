# 一、构造方法陷阱（必考）

## 1 构造方法不能写返回值

错误写法：

```java
class A {
    void A() { }
}
```

这是 **普通方法**，不是构造方法。

正确构造：

```java
class A {
    A() { }
}
```

规则：

```
构造方法 = 类名相同 + 没有返回值类型
```

---

## 2 构造方法可以重载

合法：

```java
class A {

    A() {}

    A(int x) {}

}
```

这是 **构造方法重载**

---

## 3 写了构造方法就没有默认构造

```java
class A {

    A(int x) {}

}
```

此时：

```
没有 A()
```

如果代码写：

```java
new A()
```

会 **编译错误**

---

## 4 构造方法不能继承

错误理解：

```
子类继承父类构造方法
```

实际上：

```
构造方法不能被继承
```

子类只是 **调用父类构造**

---

# 二、super / this 陷阱（高频）

## 5 this() 调用本类构造

```java
class A {

    A() {
        this(10);
    }

    A(int x) {

    }

}
```

作用：

```
调用本类其他构造方法
```

---

## 6 super() 调用父类构造

```java
class B extends A {

    B() {
        super();
    }

}
```

作用：

```
调用父类构造方法
```

---

## 7 this() 和 super() 必须第一行

错误：

```java
A() {

    int x = 10;

    super();
}
```

正确：

```java
A() {

    super();

    int x = 10;
}
```

规则：

```
this()
super()

必须第一行
```

---

## 8 this() 和 super() 不能同时存在

错误：

```java
A() {

    this(10);
    super();
}
```

原因：

```
两个都必须第一行
```

所以 **不能同时写**

---

# 三、继承初始化顺序（常考）

对象创建顺序：

```
父类成员变量
↓
父类构造方法
↓
子类成员变量
↓
子类构造方法
```

例子：

```java
class A {

    int x = 1;

    A() {
        x = 2;
    }

}

class B extends A {

    B() {
        x = 3;
    }

}
```

最终：

```
x = 3
```

# 四、方法重写（Override）

## 9 方法名必须相同

```java
class A {
    void run() {}
}

class B extends A {
    void run() {}
}
```

---

## 10 参数列表必须相同

错误：

```java
void run(int x)
```

这叫：

```
重载
```

不是重写。

---

## 11 返回值必须兼容

例如：

```java
Object test()
```

子类可以：

```java
String test()
```

因为：

```
String 是 Object 子类
```

---

## 12 访问权限不能缩小

父类：

```java
public void run()
```

子类不能：

```java
protected void run()
```

只能：

```
相同或更大权限
```

---

## 13 static 方法不能重写

```java
class A {
    static void run() {}
}

class B extends A {
    static void run() {}
}
```

这叫：

```
隐藏
```

不是 override。

---

# 五、接口陷阱（必考）

## 14 接口默认是 abstract

```java
interface A
```

等价于：

```java
abstract interface A
```

---

## 15 接口方法默认是

```
public abstract
```

例如：

```java
void run();
```

实际是：

```java
public abstract void run();
```

---

## 16 接口变量默认是

```
public static final
```

例如：

```java
int A = 10;
```

实际：

```java
public static final int A = 10;
```

所以：

```
接口变量必须初始化
```

---

## 17 类实现接口必须实现全部方法

```java
class B implements A
```

必须：

```
实现所有抽象方法
```

否则：

```
B 必须是 abstract
```

---

# 六、抽象类陷阱

## 18 抽象类不能实例化

错误：

```java
A a = new A();
```

如果：

```java
abstract class A
```

---

## 19 抽象类可以有构造方法

很多人误以为不行。

其实：

```java
abstract class A {

    A() {}

}
```

完全合法。

因为：

```
子类要调用
```

---

## 20 抽象类可以有普通方法

```java
abstract class A {

    abstract void run();

    void eat() {
        System.out.println("eat");
    }

}
```

---

# 七、最后给你一个考试秒杀口诀

基本所有题都逃不出这几条。

### 构造方法

```
类名相同
没有返回值
```

---

### 写了构造

```
默认构造消失
```

---

### 子类构造

```
第一行 super()
```

---

### 接口

```
变量：public static final
方法：public abstract
```

---

### 实现接口

```
普通类必须实现全部方法
```

否则：

```
必须 abstract
```
