### 第8题
**题干**：对于下列Hello类，哪个叙述是正确的（）
```java
class Hello {
    Hello (int m) {
    }
    int Hello () {
        return 30;
    }
    hello () {
    }
}
```
A. Hello类有两个构造方法
B. Hello类的int Hello()方法是错误的方法
C. Hello类没有构造方法
D. Hello无法通过编译

**你的错误选择**：B
**正确答案**：D

#### 详细解析
1.  先拆解类中3个方法的语法合法性：
    - `Hello(int m)`：方法名与类名完全一致、无返回值类型，是**合法的有参构造方法**。
    - `int Hello()`：方法名与类名相同，但声明了int返回值，这是**语法完全合法的普通成员方法**，仅不符合编码规范，并非错误方法，因此B选项错误。
    - `hello() { }`：Java是大小写敏感语言，`hello`与类名`Hello`不是同一个名称，因此这不是构造方法，而是普通方法。Java要求普通方法必须显式声明返回值类型（无返回值需写`void`），该方法未声明返回值，属于**语法错误**，会导致整个类编译失败。
2.  选项逐一判断：
    - A错误：类中只有1个构造方法，并非2个。
    - B错误：`int Hello()`语法合法，不是错误方法。
    - C错误：类中存在有参构造方法，并非无构造方法。
    - D正确：`hello()`方法存在语法错误，整个类无法通过编译。

#### 核心知识点
- 构造方法规则：方法名必须与类名完全一致、无任何返回值类型（连void都不能写）。
- Java大小写敏感，类名、方法名严格区分大小写。
- 普通方法必须显式声明返回值类型，无返回值必须标注`void`。

### 第9题
**题干**：给定如下Java代码，关于super的用法，以下描述正确的是（）
```java
class C extends B {
    public C(){
        super();
    }
}
```
A. 用来调用类 B 中定义的 super() 方法
B. 用来调用类 C 中定义的 super() 方法
C. 用来调用类 B 的无参构造方法
D. 用来调用类 B 中第一个出现的构造方法

**你的错误选择**：D
**正确答案**：C

#### 详细解析
1.  `super`是Java关键字，用于子类访问父类成员，`super()`是子类构造方法中调用父类构造方法的固定语法：
    - `super()` 固定调用父类的**无参构造方法**，必须放在子类构造方法的第一行。
    - 只有带参数的`super(参数列表)`，才会根据参数匹配调用父类对应的有参构造方法。
2.  选项逐一判断：
    - A、B错误：`super()`不是类中定义的方法，是Java关键字语法，不存在“类中定义的super()方法”。
    - C正确：`super()`的核心作用就是调用父类B的无参构造方法。
    - D错误：`super()`只匹配父类的无参构造，和父类构造方法的定义顺序无关。

#### 核心知识点
- 子类构造方法必须在第一行调用父类构造方法，未显式书写`super()`时，编译器会自动添加无参的`super()`。
- `super()`调用父类无参构造，`super(参数)`调用对应参数列表的父类有参构造。

### 第10题
**题干**：分析下列程序的结果是（）
```java
class Super {
    public int i = 0;
    public Super (String text) {
        i = 1;
    }
}
public class Sub extends Super {
    public Sub (String text) {
        i = 2;
    }
    public static void main (String[] args) {
        Sub sub = new Sub("Hello");
        System.out.println(sub.i);
    }
}
```
**你的错误选择**：D
**正确答案**：A（对应结果：编译失败）

#### 详细解析
1.  核心语法规则：当类中手动定义了构造方法后，Java编译器**不会再为该类生成默认的无参构造方法**。
2.  代码错误分析：
    - 父类`Super`手动定义了有参构造`Super(String text)`，因此父类没有默认的无参构造方法。
    - 子类`Sub`的构造方法中，没有显式调用父类的构造方法，编译器会自动在子类构造方法第一行添加`super()`（调用父类无参构造）。
    - 父类不存在无参构造，`super()`调用失败，代码存在语法错误，**无法通过编译，更无法运行**。
3.  补充说明：若子类构造方法中显式添加`super(text);`，代码可正常运行，最终输出结果为`2`（执行流程：父类成员初始化i=0 → 父类构造方法i=1 → 子类构造方法i=2）。

#### 核心知识点
- 子类构造方法必须调用父类构造方法，隐式/显式调用都必须保证父类存在对应的构造方法。
- 手动定义构造方法后，编译器不再生成默认无参构造。

## 二、填空题知识点整理
### 第20题
**题干**：JDK8 以后接口中包含 ______、______ 、______ 、______。
**正确答案**：抽象方法、默认方法（default方法）、静态方法（static方法）、私有方法（private方法）

#### 知识点解析
- JDK8之前：接口中只能存在`public abstract`的抽象方法，以及`public static final`的常量。
- JDK8新增：允许接口定义`default`默认方法（带方法体，供实现类继承/重写）、`static`静态方法（带方法体，仅能通过接口名调用）。
- JDK9新增：允许接口定义`private`私有方法（带方法体，供接口内部的默认/静态方法复用），因此JDK8及以后的接口，完整包含上述4种方法类型。

### 第21题
**题干**：如果一个类实现一个接口，但不重写接口的所有方法，则该类应该是 ______ 类。
**正确答案**：抽象

#### 知识点解析
- 普通非抽象类实现接口时，必须重写（实现）接口中所有的抽象方法，否则会编译报错。
- 只有**抽象类**可以不实现接口的全部抽象方法，剩余未实现的抽象方法，需由继承该抽象类的普通子类完成实现。
