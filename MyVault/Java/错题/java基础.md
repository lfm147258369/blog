关于抽象类和接口叙述正确的是？ ( )

A
抽象类和接口都能实例化的
B
抽象类不能实现接口
C
抽象类方法的访问权限默认都是public
D
接口方法的访问权限默认都是public

| 特性        | 抽象类               | 接口              |
| --------- | ----------------- | --------------- |
| 能否实例化     | 不可以               | 不可以             |
| 是否可以实现接口  | 可以                | —               |
| 方法默认权限    | default           | public          |
| 方法默认修饰    | abstract（如果声明为抽象） | public abstract |
| 是否可以有普通方法 | 可以                | Java8以后可以       |
