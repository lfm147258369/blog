# 题意拆解

- 给你一个二维数组， 由`0` 和 `1` 组成，0代表空位， 1 代表被占据的位置
- 现在我们要在上面贴一个长h宽w的邮票，遍历一遍，看能不能被贴完，所有0的位置

# 思路
1. 要遍历二维数组，要解决一下问题：
	1. 该区域能不能贴邮票？如何判断？
	2. 贴了之后如何处理数组？
	3. 如何判断所有的0区域有没有被覆盖？
2. 解决问题的思路
	1. 这是一个二维数组，如果判断区域都是0，那么这个区域的区间和就全部是0， 所以判断能不能贴邮票就转变成这个区域的区间和是否为0。 那么我们就要 先对二维数组进行前缀和处理。
	   ```java
		int n = grid.length; int m =grid[0].length;//grid为原数组
		int[][] sum = new int[n + 1][m + 1];
		for (int i = 1; i <= n; i ++) { 
			for (int j = 1; j <= m; j ++) { 
				sum[i][j] = grid[i - 1][j - 1];
			}
		}
		build(sum);
        int[][] diff = new int[n + 2][m + 2];
        for (int a = 1, c = a + h - 1; c <= n; c ++, a ++) { 
            for (int b = 1, d = b + w - 1; d <= m; b ++, d++) {
                if (sumRegion(sum, a, b, c, d) == 0) { 
                    add(diff, a, b, c, d);
                }
            }
        }
	   ```
	2. 判断能贴了之后我们就把这个区域全部化为`1` 代表被占据了，我们可以利用差分数组。 把所有的处理好之后， 再做一次前缀和，就可以表示该区域贴了邮票
	   ```java
	   
	private static void add(int[][] diff, int a, int b, int c, int d){
		diff[c + 1][d + 1] += 1;
		diff[a][b] += 1;
		diff[c + 1][b] -= 1;
		diff[a][d + 1] -= 1;
	}
	
	 ``` 
	   3. 要判断所有区域是否倍覆盖， 就看我们贴完之后的数组和原数组对比，如果原数组中为0， 而贴完了邮票的数组也为0，代表这个应该被覆盖的位置没有被覆盖直接返回false
	      ```java
        for (int i = 1; i <= n; i ++) { 
            for (int j = 1; j <= m; j ++) { 
                if (diff[i][j] == 0 && grid[i - 1][j - 1] == 0) { 
                    return false;
                }
            } 
        }
	      ```
	      

# 总流程
```java
class Solution {
    public  boolean possibleToStamp(int[][] grid, int h, int w) {
        int n = grid.length; int m =grid[0].length;
        int[][] sum = new int[n + 1][m + 1];
        for (int i = 1; i <= n; i ++) { 
            for (int j = 1; j <= m; j ++) { 
                sum[i][j] = grid[i - 1][j - 1];
            }
        }
        build(sum);
        int[][] diff = new int[n + 2][m + 2];
        for (int a = 1, c = a + h - 1; c <= n; c ++, a ++) { 
            for (int b = 1, d = b + w - 1; d <= m; b ++, d++) {
                if (sumRegion(sum, a, b, c, d) == 0) { 
                    add(diff, a, b, c, d);
                }
            }
        }
        build(diff);
        for (int i = 1; i <= n; i ++) { 
            for (int j = 1; j <= m; j ++) { 
                if (diff[i][j] == 0 && grid[i - 1][j - 1] == 0) { 
                    return false;
                }
            } 
        }
        return true;
    }
    //构建二维前缀和
    private static void build(int[][] sum) { 
        for (int i = 1; i < sum.length; i ++) { 
            for (int j = 1; j < sum[0].length; j ++) { 
                sum[i][j] += sum[i - 1][j] + sum[i][j - 1] - sum[i - 1][j - 1]; 
            }
        }
    }
    //计算该区域能不能贴邮票
    private static int sumRegion(int[][] diff, int a, int b, int c, int d) { 
        return diff[c][d] - diff[c][b - 1] - diff[a - 1][d] + diff[a - 1][b - 1];
    }
    //进行差分处理
    private static void add(int[][] diff, int a, int b, int c, int d) { 
        diff[c + 1][d + 1] += 1;
        diff[a][b] += 1;
        diff[c + 1][b] -= 1;
        diff[a][d + 1] -= 1;
    }
}
```
