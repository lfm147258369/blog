1. 估计 `最终答案可能的范围` 是什么
2. 分析 `问题的答案` 和 `给定条件之间` 的 `单调性` , 大部分时候只需用到`自然智慧` 
3. 建立一个f函数， `当答案固定的情况下` ， 判断 `给定的条件是否达标`
4. 在`最终答案可能的范围上不断二分搜索` ,每次用f函数判断，直到二分结束，找到`最合适的答案`


# [LeetCode875](https://leetcode.cn/problems/koko-eating-bananas/description/) 


## 题意拆解
1. 给一个数组`piles`, n为数组长度，每个元素`piles[i]` 代表第i堆有几个香蕉， 还有一个h参数，代表管理员离开h小时
2. 以下面这个数组为例子
   ```
   [3, 6, 7, 11]
   ```
当速度为4的时候，哪怕大于第一个元素3了，也不往下继续了，会停住。
3. 问题是:如何设置一个尽量小的速度，让它能够在管理员回来前吃完香蕉

## 思路分析
1. 我们寻找答案，这个答案存在边界吗？
   存在的。我们先尝试从0开始，如果这个数组一个香蕉都没有那么速度为0的时候就是最合适的，可是我们看题目信息：
   ```
    1 <= piles.length <= 104
    piles.length <= h <= 109
    1 <= piles[i] <= 109
   ```
   那么最小的速度就是1了，那么最大呢？
2. 我们可以根据以下例子来分析
   ```
   piles = [30,11,23,4,20]
   ```
当我们的速度超过了30还有意义吗？30是数组元素的`最大值` ，当为30的时候，吃任何一堆都是一次，超过了再找`答案`是 `无意义的` 超过`最大 ` 元素的速度已经没有区别了，而且我们要使速度尽量`小` 。
3. 所以我们答案的区间就锁定在`1 -> MAX` 
4. 我们在`1 -> MAX` 不断尝试答案，找到一个尽量小的，所需时间小于`h` 的速度，怎么样找最有`效率` 
5. 考虑到`单调性` ，我们可以引入`二分` ，如果这个速度满足了条件，就继续往左边二分，看还有没有更小且满足的答案， 如果不满足，说明这个速度太小，要往右找。

## 代码
```java
class Solution {
    public int minEatingSpeed(int[] piles, int h) {
        int l = 1; 
        int r = 0;
        for (int p : piles) { 
            r = Math.max(p, r);
        }
        int ans = 0;
        int m = 0;
        while (l <= r) { 
            m = l + ( (r - l) >> 1 ) ;
            if (f(piles, m) <= h) { 
                ans = m;
                r = m - 1;
            } else { 
                l = m + 1;
            }
        }
        return ans;
    }
    private static long f(int[] piles, int speed) {
        long ans = 0;
        for (int pile : piles) { 
            ans += (pile + speed - 1) / speed;
        }
        return ans;
    }
}
```

# [画匠问题](https://leetcode.cn/problems/split-array-largest-sum/)

- 题意理解

给你一个数组，数组每个元素代表完成一副画需要的时间。
然后再给你一个数字`n` 代表有`n` 个画师
- 细节
每个画师只能选取数组`连续` 的部分， 
- 问题
现在问，我们要怎么给这些画师分配任务才能让每个画师完成任务的`时间尽量少` 呢？


- 题目例子
```
[7, 2, 5, 10, 8] k=2

output:
18
```

第一个画师选`7, 2, 5` 第二个选`10, 8` , 这两部分选`较大的` 那部分，返回，故返回`18`

也就是说我们要使划分的连续子数组的`前缀和`尽可能小

## 思路
1. 答案有范围吗？
有范围，最小是`0` ,题目给的数据最小是0。最大呢？最大就是一个画家把所有画包完，那么所有画包完就是这个数组`整体的前缀和` 
2. 有单调性吗？
有的。我们先从中间找，我们要求在每部分不超过`m(中间值)`  的情况下，看能返回几部分，如果我们的返回值`>= k` 说明什么？

看下面例子

```
[8, 7, 6, 5, 4, 10] k=2
```

我先不取中间的，我先取一个能使它返回大于等于k的，例如`4`
![[Pasted image 20251007213206.png]]

我们会发现，这个值`过小`  了，以至于我们没走几步就要划分一次，可是我们有2个画家而已，如果按照4这个限制的化就不行，所以该去`右侧` 进行二分。

于是，我们构建出了二分查找的架构:
```java
class Solution {
    public int splitArray(int[] nums, int k) {
        long sum = 0;
        for (int x : nums) { 
            sum += x;
        }
        int ans = 0;
        for (int l = 0, r = sum, m ; l <= r) { 
            m = l + ((r - l) >> 1);
            if (f(nums, m) > k) { 
                l = m + 1;
            } else { 
                r = m - 1;
                ans = m;
            }
        }
        return ans;
    }
}
```


3. 建立一个f函数， `当答案固定的情况下` ， 判断 `给定的条件是否达标`

我们的f函数要返回在m这个限制下，把整个数组划分成了几份，参考上面的图，我们可以知道，如果当前的值加上之前的前缀和大于了限制，那么就要马上进行划分，然后重新从该位置出发，计算前缀和。循环往复

```java
    private static int f(int[] nums, long limit) {
        long sum = 0;
        int parts = 1;
        for (int x : nums) {
            if (x > limit) {
                return Integer.MAX_VALUE;
            }
            if (sum + x > limit) { 
                parts++;
                sum = x;
            } else { 
                sum += x;
            }
        }
        return parts;
    }
```



## 答案
```java
class Solution {
    public int splitArray(int[] nums, int k) {
        long sum = 0;
        for (int x : nums) { 
            sum += x;
        }
        long ans = 0;
        for (long l = 0, r = sum, m ;l <= r;) { 
            m = l + ((r - l) >> 1);
            if (f(nums, m) > k) { 
                l = m + 1;
            } else { 
                r = m - 1;
                ans = m;
            }
        }
        return (int)ans;
    }
    private static int f(int[] nums, long limit) {
        long sum = 0;
        int parts = 1;
        for (int x : nums) {
            if (x > limit) {
                return Integer.MAX_VALUE;
            }
            if (sum + x > limit) { 
                parts++;
                sum = x;
            } else { 
                sum += x;
            }
        }
        return parts;
    }
}
```
