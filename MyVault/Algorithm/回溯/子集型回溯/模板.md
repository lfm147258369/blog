# 题目链接
[Leetcode1286字母组合迭代器](https://leetcode.cn/problems/iterator-for-combination/description/)

# 尝试思路

- 无法理解:函数 _`hasNext()`_ ，只有存在长度为 `combinationLength` 的下一个字母组合时，才返回 `true`

 - 什么样的情况才是true？


 - 重新理解：
 - 既然为迭代器，就要知道在哪里结束，所以要判断当前组合是不是最后一个组合
- 那么题目要枚举给定长度的字符串组合，还要按照字典序来排序，那么要保证当前枚举的字符在字典序上要大于上一个枚举的字符
- 再根据题目的条件，给的是有序的字符串，那么我们就可以用`for` 来进行枚举，保证下一层枚举的字符在字符串中一定位于当前枚举枚举字符 的后面


- 第一次代码：
```cpp
class CombinationIterator
{
private:
    string path;
    vector<string> ans;
public:
    CombinationIterator(string characters, int combinationLength)
    {
        dfs(0, combinationLength, characters);
        reverse(ans.begin(), ans.end());
    }
    void dfs(int index, int n, string & str)
    {
        if (path.size() == n)
        {
            ans.emplace_back(path);
            return ;
        }
        for (int i = 0 ; i < str.size(); i++)
        {
            path.push_back(str[i]);
            dfs(index + 1, n, str);
            path.pop_back();//恢复现场
        }
    }
    string next()
    {
        string str = ans[ans.size() - 1];
        ans.pop_back();
        return str;
    }

    bool hasNext()
    {
        return path.size() > 0;
    }
};

```
