# 大概架构

整体架构
整体架构可以类比学生管理系统，将不同的功能模块封装到不同的类中，以提高代码的可维护性和可扩展性。
类的设计
1. 图书类（Book）

    属性：
        书名（string 类型）
        序号（string 类型，用于唯一标识图书）
        作者（string 类型）
        借阅状态（bool 类型，true 表示已借出，false 表示可借阅）
    方法：
        构造函数：用于初始化图书的基本信息。
        显示图书信息的方法：将图书的书名、序号、作者和借阅状态输出。
        重载输出流运算符：方便输出图书信息。
        改变借阅状态的方法：用于借书和还书时修改借阅状态。

2. 管理员类（Administrator）

    属性：
        管理员账户（string 类型）
        管理员密码（string 类型）
    方法：
        构造函数：初始化管理员账户和密码。
        登录验证方法：验证输入的账户和密码是否正确。
        添加图书方法：将新的图书信息添加到图书列表中。
        删除图书方法：根据图书序号从图书列表中删除指定图书。
        修改图书信息方法：根据图书序号修改图书的书名、作者等信息。
        查询图书信息方法：可以根据书名、序号、作者等条件查询图书信息。

3. 读者类（Reader）

    属性：
        读者账户（string 类型）
        读者密码（string 类型）
        借阅的图书列表（vector&lt;string&gt; 类型，存储借阅的图书序号）
    方法：
        构造函数：初始化读者账户和密码。
        登录验证方法：验证输入的账户和密码是否正确。
        查询图书信息方法：可以根据书名、序号、作者等条件查询图书信息。
        借书方法：根据图书序号尝试借阅图书，如果图书可借阅，则修改图书的借阅状态，并将图书序号添加到读者的借阅列表中。
        还书方法：根据图书序号归还图书，修改图书的借阅状态，并从读者的借阅列表中移除该图书序号。

4. 管理系统类（LibraryManagementSystem）

    属性：
        图书列表（vector&lt;Book&gt; 类型，存储所有图书信息）
        管理员列表（vector&lt;Administrator&gt; 类型，存储所有管理员信息）
        读者列表（vector&lt;Reader&gt; 类型，存储所有读者信息）
    方法：
        构造函数：初始化图书列表、管理员列表和读者列表，可以从文件中读取初始数据。
        主菜单显示方法：显示系统的主菜单，提供登录选项（管理员登录、读者登录）和退出系统选项。
        管理员登录处理方法：调用管理员的登录验证方法，验证成功后进入管理员操作菜单。
        读者登录处理方法：调用读者的登录验证方法，验证成功后进入读者操作菜单。
        管理员操作菜单显示方法：显示管理员可以进行的操作选项（添加图书、删除图书、修改图书信息、查询图书信息等），并根据用户选择调用相应的方法。
        读者操作菜单显示方法：显示读者可以进行的操作选项（查询图书信息、借书、还书等），并根据用户选择调用相应的方法。
        数据保存方法：将图书列表、管理员列表和读者列表的信息保存到文件中，以便下次启动系统时恢复数据。

数据存储
可以使用文件来存储图书信息、管理员信息和读者信息，在系统启动时从文件中读取数据，在系统退出时将数据保存到文件中。文件格式可以选择文本文件，使用分隔符（如制表符或逗号）来分隔不同的字段。
交互流程

    启动系统，显示主菜单。
    用户选择登录类型（管理员登录或读者登录），输入账户和密码进行登录验证。
    登录成功后，根据用户类型显示相应的操作菜单。
    用户选择操作选项，系统调用相应的方法执行操作。
    操作完成后，返回操作菜单，直到用户选择退出系统。
    退出系统时，将数据保存到文件中。
