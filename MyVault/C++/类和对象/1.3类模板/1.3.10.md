### 1. 拷贝构造函数 vs. 赋值运算符的区别
| 特性                 | 拷贝构造函数 (MyArray(const MyArray& arr)) | 赋值运算符 (operator=)                |
|----------------------|---------------------------------------------|---------------------------------------|
| 调用时机             | 对象初始化时（如 `MyArray a = b;`）        | 对象已存在时（如 `a = b;`）           |
| 左侧对象状态         | 尚未构造（内存未分配）                      | 已构造（可能有旧数据）                |
| 是否需要释放旧内存   | ❌ 不需要（对象刚创建）                     | ✔️ 必须（否则内存泄漏）               |
| 典型使用场景         | `MyArray a(b);` 或 `MyArray a = b;`         | `a = b;`（`a` 已存在）                |


### 2. 为什么不能只依赖拷贝构造函数？
#### 场景 1：对象已存在时赋值
```cpp
MyArray&lt;int&gt; a(10);  // a 已初始化
MyArray&lt;int&gt; b(5);    // b 已初始化
b = a;               // 调用的是 operator=，不是拷贝构造！
```
- 如果只有拷贝构造函数，`b = a;` 不会调用它，而是使用编译器生成的浅拷贝赋值，导致内存泄漏和双重释放。

#### 场景 2：自赋值问题
```cpp
MyArray&lt;int&gt; a(10);
a = a;  // 自赋值
```
- 如果没有正确实现 `operator=`，可能会先 `delete[] pAddress`，导致数据丢失。  
- 正确实现需检查自赋值：  
  ```cpp
  MyArray& operator=(const MyArray& arr) {
      if (this != &arr) {  // 防止自赋值
          delete[] pAddress;  // 释放旧内存
          // 深拷贝逻辑...
      }
      return *this;
  }
  ```


### 3. 如果只写拷贝构造，不写 operator= 会发生什么？
#### 问题 1：默认浅拷贝赋值
编译器生成的默认 `operator=` 仅简单复制指针（浅拷贝），导致：  
- 内存泄漏（左侧对象的旧数组未释放）  
- 双重释放（两个对象指向同一块内存，析构时崩溃）

#### 问题 2：无法处理动态资源
`MyArray` 管理动态数组时，必须：  
1. 释放旧内存（避免泄漏）  
2. 分配新内存（深拷贝）  
3. 复制数据（保持独立性）  
这些逻辑无法通过拷贝构造函数实现，因为 `operator=` 需要额外处理已存在的对象。


### 4. 正确实现 operator= 的要点
```cpp
MyArray& operator=(const MyArray& arr) 
{
    if (this != &arr) 
    {                   // 1. 检查自赋值
        delete[] pAddress;                // 2. 释放旧内存
        m_Capacity = arr.m_Capacity;      // 3. 复制容量
        m_Size = arr.m_Size;              // 4. 复制大小
        pAddress = new T[m_Capacity];     // 5. 分配新内存
        for (int i = 0; i < m_Size; i++) 
        { // 6. 复制数据
            pAddress[i] = arr.pAddress[i];
        }
    }
    return *this;                         // 7. 返回自身引用
}
```


### 5. 总结：为什么必须同时实现拷贝构造和 operator=？
| 操作                | 是否需要 | 原因                                  |
| ----------------- | ---- | ----------------------------------- |
| 拷贝构造函数            | 需要   | 处理对象初始化时的深拷贝（如 `MyArray a = b;`）。   |
| 赋值运算符 `operator=` |  需要  | 处理对象已存在时的赋值（如 `a = b;`），需释放旧内存并深拷贝。 |
| 析构函数              | 需要   | 释放动态分配的内存，避免泄漏。                     |

#### C++ 三大法则（Rule of Three）
- **拷贝构造函数**用于初始化时的深拷贝。  
- **赋值运算符**用于已存在对象的赋值，需额外处理旧内存。  
- 只实现其中一个会导致内存管理错误（泄漏或崩溃），必须同时实现并确保逻辑一致！

# 代码
##  `MyArray.hpp` 文件
```cpp
#include &lt;iostream&gt;
using namespace std;
template<class T>

class MyArray
{
public:
    //有参构造
    MyArray(int capacity)
    {
        //cout << "MyArray的有参构造调用" << endl;
        this->m_Capacity = capacity;
        this->m_Size = 0;
        this->pAddress = new T[this->m_Capacity];
    }
    //尾插法
    void Push_Back(const T & value)
    {
        if (this->m_Capacity == this->m_Size)
        {
            return ;
        }
        this->pAddress[this->m_Size] = value;
        this->m_Size++;
    }
    void Pop_Back()
    {
        if (this->m_Size == 0)
        {
            return;
        }
        this->m_Size--;
    }
    //通过下标访问数组中的元素
    //作为左值返回引用
    T &operator[](int index)
    {
        return this->pAddress[index];
    }
    ~MyArray()
    {
        //cout << "MyArray的析构调用" << endl;
        if (this->pAddress != nullptr)
        {
            delete[] this->pAddress;
            pAddress = nullptr;
        }
    }
    //拷贝构造
    MyArray(const MyArray& arr)
    {
        ///cout << "MyArray的拷贝调用" << endl;
        this->m_Capacity = arr.m_Capacity;
        this->m_Size = arr.m_Size;

        //深拷贝
        this->pAddress = new T[arr.m_Capacity];
        //将Array中的数据都拷贝过来
        for (int i = 0; i < this->m_Size; i++)
        {
            this->pAddress[i] = arr.pAddress[i];
        }
    }
    //operator=防止浅拷贝问题
    MyArray & operator=(const MyArray& arr)
    {
        //cout << "MyArray的重载调用" << endl;
        //先判断原来堆区是否释放，如果有先释放
        if (this->pAddress != nullptr)
        {
            delete[]this->pAddress;
            this->pAddress = nullptr;
            this->m_Capacity = 0;
            this->m_Size = 0;
        }
        //深拷贝
        this->m_Capacity = arr.m_Capacity;
        this->m_Size = arr.m_Size;
        this->pAddress = new T[arr.m_Capacity];
        return *this;
    }
    //返回数组容量
    int GetCapacity()
    {
        return this->m_Capacity;
    }
    //返回数组大小
    int getSize()
    {
        return this->m_Size;
    }
private:
    T* pAddress;//指针指向堆区开辟的真实数组

    int m_Capacity;//数组容量

    int m_Size;//数组大小

};


```
