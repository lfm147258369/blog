
- 类模板的分文件编写问题以及解决
- 要考虑这个问题是因为类模板 的创建时机在调用的阶段，因此直接包含.h文件的时候，它不会找到.cpp文件里面的实现所以导致它无法运行


- 两种方案：
- 1.直接包含源文件(不常用)
- 2.把模板类的头文件改为.hpp文件

- 主函数
```cpp
#include <iostream>
#include <string>
//第一种解决方式，直接包含源文件
// #include "Person.cpp"

//第二种解决方式:将.h和.cpp中的内容写在一起，改后缀名为.hpp文件
#include "Person.hpp"
using namespace std;


void test01()
{
    Person<string, int> p ("lifumin", 19);
    p.showPerson();
}

int main()
{
    test01();
    return 0;
}

```

- 源文件 
```cpp
#include "Person.h"
 template<class T1, class T2>
 Person<T1, T2>::Person(T1 name, T2 age)
 {
     this->m_Name = name;
     this->m_Age = age;
 }


 template <class T1, class T2>
 void Person<T1, T2>::showPerson()
 {
     cout << "姓名 : " << this->m_Name << "年龄 : " << this->m_Age << endl;
 }

```

-  头文件(.h)/.hpp文件
```cpp
#ifndef PERSON_H
#define PERSON_H

#include <iostream>
using namespace std;
template<class T1, class T2>
class Person
{
public:
    Person(T1 name, T2 age);
    void showPerson();
private:
    T1 m_Name;
    T2 m_Age;
};


template<class T1, class T2>
Person<T1, T2>::Person(T1 name, T2 age)
{
    this->m_Name = name;
    this->m_Age = age;
}


template <class T1, class T2>
void Person<T1, T2>::showPerson()
{
    cout << "姓名 : " << this->m_Name << "年龄 : " << this->m_Age << endl;
}


#endif //PERSON_H

```
