# 将十进制转化为任意进制数的模板
- 假设转换为k进制
- 将十进制数的每一位存入数组中。
- 然后 x += %10 * 对应的进制数, /=10。
- ![[Pasted image 20250105154720.png]]
![[Pasted image 20250105154648.png]]

- 将十进制数字转换为M进制数字
- 将十进制数x % M,然后利用映射字符数组，找到其数字对应的字符，追加到字符串ans中
- 由于不断的 % M， /M，字符串的顺序是左边低位右边高位，因此需要逆序输出最终的结果
