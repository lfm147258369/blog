- `[2, 3, 5]`
```
result[0] = |2-2| + |2-3| + |2-5| = 0 + 1 + 3 = 4，
result[1] = |3-2| + |3-3| + |3-5| = 1 + 0 + 2 = 3，

```

- `res[0] = 2 + 2之前的区间和(0) + 2之后的前缀和(5 - 3 = 2) = 4`
- 因为题目给的数据是非递减的有序整数数组
- 那么思路就可以从`当前元素挨个减去每个元素绝对值` 转化为`用当前元素值+当前元素之前的前缀和 + 当前元素后面的区间和`
- 由于都是整数，而且有序还省去了反复求绝对值的过程

- 那么map中要存储的就是每个前缀和最早出现的下标
- 存储的时候怎么调用出来进行处理，怎么找到当前下标i之前的区间和？用一个变量来存储之前的成为`左和` ，那还需要一个`右和` 来记住a它右边的和
```
对于i的左边：
nums[i]必然大于左边的所有元素，所以可以数出左边的元素个数，即i个
now_left  = (nums[i] - nums[0]) + (nums[i] - nums[1]) +
            (nums[i] - nums[i - 1])
合并后就为:
now_left  = i * nums[i] - (nums[0] + nums[1] + nums[i - 1]) 
			i * nums[i] - leftsum

```
